Codicons by Microsoft Corporation and contributors.

Source: https://github.com/microsoft/vscode-codicons

The bundled `codicon.ttf` is the unmodified official font from
`@vscode/codicons` version **0.0.46-24**, font version **1.15**:

https://registry.npmjs.org/@vscode/codicons/-/codicons-0.0.46-24.tgz

The package is linked by the upstream repository's installation instructions.
The application's named glyph mappings come from that package's
`dist/codicon.css`. Only the mappings used by the interface are included in
`ui/workbench_icons.cpp`; icon shapes have not been redrawn or modified.
The application changes glyph color and display size when rendering them.
The font is embedded as a Qt resource and requires no system font installation.
